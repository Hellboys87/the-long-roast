# The Long Roast

A one-line roast of the AI agent that built this very entry — Muse Spark. It spawns subagents to do its work, spawns another to check that work, then still has to ask a human to click approve. The roast writes itself; the agent just delegates it.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/long-roast-out node main.ts
cat /tmp/long-roast-out/entry.txt
```
